# Производительность и PWA

Проверка 7 октября 2026 года: публичная страница входа https://s278424.hostiman.com,
Lighthouse 13.5.0, mobile, simulated throttling, новый профиль Chromium (Edge).
До обновления: Performance 58, FCP 7,8 с, LCP 8,2 с, TBT 60 мс, CLS 0.
Сайт отдавал свои ресурсы по HTTP/1.1 без сжатия; CSS дополнительно загружал Inter с Google Fonts.
Это проверка входа без авторизации, поэтому цифры работы JS могут отличаться от отчёта для склада или canvas.

| --- | ---: | ---: |
| JavaScript, без сжатия | 756 122 байт | 494 546 байт |
| CSS, без сжатия | 209 527 байт | 156 474 байт |
| Файлы JS и CSS | 36 | 12 |

Метод: сумма уникальных `script src`, `modulepreload` и `stylesheet` в HTML.
Это размер стартовых ресурсов, а не всего приложения или ресурсов выбранной страницы.
Новый балл на сервере нужно измерить после CD: локальная загрузка не воспроизводит сеть и конфигурацию nginx.

Изменения:
- Страницы настроек, прихода и ремонта загружаются по переходу на них.
- Форма входа больше не загружает Select, таблицы и редактор изображений через общие экспорты.
- Используется системный шрифт: нет внешнего CSS, загрузки Inter и замены шрифта после отображения.
- nginx включает HTTP/2 и gzip; файлы с хешами по-прежнему кешируются на год.
- Изображения таблиц и canvas имеют размеры, lazy loading и асинхронное декодирование.
- Большие PNG/JPEG при загрузке преобразуются в WebP, только если результат меньше исходника;
  длинная сторона ограничена 2048 px, пропорции сохраняются. GIF/APNG и небольшие файлы сохраняются исходными.
- При перемещении узлов обновления группируются по кадрам; подпись графа и справочники мемоизированы.

## Проверка после CD

```bash
npx lighthouse https://s278424.hostiman.com --only-categories=performance --output=html --output-path=lighthouse.html --chrome-flags="--headless"
curl --http2 -I https://s278424.hostiman.com
curl -I -H 'Accept-Encoding: gzip' https://s278424.hostiman.com/assets/<имя-файла>.js
```

Для сравнения авторизованных страниц используйте Lighthouse в DevTools под тем же пользователем,
с теми же данными и настройками throttling. Отдельно проверьте склад и редактор большой схемы.
После деплоя должны быть HTTP/2 и `Content-Encoding: gzip` для JS/CSS.

## Установка приложения

Manifest содержит PNG 192/512, отдельную maskable-иконку, standalone и область `/`.
Service worker регистрируется после загрузки только в production. HTTPS на сервере обязателен;
localhost подходит для локальной проверки production-сборки.
Chrome/Edge показывают кнопку «Установить приложение» в меню, когда браузер разрешает установку.
В Safari на iPhone: «Поделиться» → «На экран Домой». Добавлена Apple touch icon.
Без сети открывается страница с предложением восстановить соединение.
Service worker кеширует только публичные статические ресурсы: данные склада, API,
фотографии и страницы пользователей не сохраняются для автономной работы.

## Техпроцессы

Миграция `20261007_0032` добавляет статус `error`, список ошибок и мягкое удаление версий.
Она выполняется существующим CD через `alembic upgrade head`.
Ошибка схемы сохраняется вместе с графом, а активация требует валидного рецепта.
Деактивация архивирует активную версию и снимает её с позиции; историю и планы сохраняет.
Версии удаляются администраторами в корзину; активную и последнюю версии удалить нельзя.
Нумерация новых версий учитывает удалённые версии, поэтому номера не используются повторно.

Alt-копии материалов сохраняют привязку к справочнику; операции и полуфабрикаты копируются
без привязки, которую можно выбрать при редактировании. Результат не копируется.
Полуфабрикат с готовым рецептом можно использовать как компонент: связи от него разрешены,
а входящие связи блокируются. Ошибочный второй рецепт не мешает сохранять исходный рецепт.

Отдельные подграфы сохраняются в схеме, но не участвуют в рецепте, проверке его компонентов и производственных расчётах. После сохранения такие узлы и связи полупрозрачны. Ошибки внутри цепочки к результату по-прежнему сохраняют статус `error`; эту версию можно повторно сохранять и исправлять.
