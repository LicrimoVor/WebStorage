## SEO frontend

Проект описан в README как приватная производственная система. Правильная текущая
стратегия — исключать рабочие страницы и инструкции из поисковой выдачи.
`noindex` — указание добросовестному поисковику, а не защита конфиденциальных данных.

| Проверка | Результат |
| --- | --- |
| Язык, кодировка, viewport | Есть `lang="ru"`, UTF-8, адаптивный viewport |
| Индексация без JavaScript | `robots` и `googlebot` с noindex присутствуют уже в index.html |
| robots.txt | `Allow: /` позволяет прочитать noindex; заменять это на `Disallow: /` не нужно |
| HTTP-заголовки | FastAPI добавляет X-Robots-Tag, API получает Cache-Control: no-store; для отдельно размещённого frontend заголовки нужно проверить на его сервере |
| Заголовки разделов | Хук задаёт русские title/description и Open Graph; основные страницы имеют main и h1 |
| Социальные метаданные | Базовые OG-теги, locale и twitter:card присутствуют; динамические Twitter-теги дополнены |
| Favicon и manifest | Присутствуют; manifest сам по себе не означает поддержку offline/PWA |
| Sitemap и canonical | Не обязательны для приватных noindex-страниц; нельзя включать токены публичных инструкций в sitemap или OG URL |
| Производительность | Разделы загружаются через React.lazy; production build проходит. Размер JS не заменяет измерение LCP/INP/CLS в браузере |

Google рекомендует разрешать обход страниц с noindex, иначе робот не увидит
директиву: [официальное описание noindex](https://developers.google.com/search/docs/crawling-indexing/block-indexing).
При noindex в исходном HTML Google может не выполнять JavaScript, поэтому динамические
метаданные не делают приложение публично индексируемым:
[JavaScript SEO](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics).

Если нужна органическая аудитория, следует создать отдельную публичную страницу продукта
со статически сформированным или серверным HTML: описание, сценарии использования,
демонстрационные изображения без рабочих данных, контакты. Для неё нужны собственные
title/description, canonical реального домена, OG image и sitemap публичных страниц.
Не следует снимать noindex со всего приложения ради продвижения.

## Оставшиеся риски и приоритеты

1. **Высокий, конфиденциальность media.** `app/main.py` монтирует `/media` через
   StaticFiles без проверки сессии. UUID затрудняет угадывание, но известный URL
   доступен без входа и после отзыва ссылки инструкции. Нужна модель защищённых
   вложений: внутренняя выдача по сессии и отдельная выдача через действующий токен
   опубликованной инструкции. Переход требует учёта уже сохранённых Markdown-URL и
   старых версий документов; простое закрытие каталога сломает публичные инструкции.
2. **Средний, права на агрегаты.** После исправления финансового журнала нужна
   единая матрица доступа к аналитике, зарплате и всем наборам экспорта. Финансовые
   показатели входят и в агрегированные отчёты; ограничение одного endpoint не
   является полной изоляцией всей финансовой информации.
3. **Средний, ресурсы при экспорте.** `exports/service.py` синхронно формирует полный
   XLSX в памяти; StreamingResponse передаёт уже готовые байты. Есть ограничение
   100 000 строк, но оно не исключает задержки event loop и расход памяти. Следующий
   шаг — фоновая задача с лимитом параллельности, временным файлом и сроком хранения.
4. **Средний, защита входа под нагрузкой.** Блокировка учётной записи уже есть.
   Перенос Argon2 в поток не заменяет ограничения частоты запросов и числа
   параллельных вычислений на сервере/reverse proxy.
5. **Средний, загрузки.** `media/service.py` проверяет сигнатуру и размер, но не
   декодирует изображение целиком. Желательны ограничения пикселей и проверка
   декодирования, а также квоты и очистка неиспользуемых файлов.
6. **Эксплуатация.** Нужны проверяемое восстановление PostgreSQL и media из резервной
   копии, мониторинг ошибок и проверка готовности БД отдельно от liveness. Docker
   Compose публикует порт PostgreSQL без ограничения loopback — для размещения
   вне локальной машины следует закрыть порт сетевыми правилами или изменить binding.
