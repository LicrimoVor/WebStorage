# Производство, выпуск и продажа

Производство расходует комплектующие и добавляет свободный остаток. Выпуск в
«Планирование → Выпуск продукции» и на складе — отдельное действие: присваивает
введённые вручную ID уже имеющимся товарам. Техпроцесс и сотрудники для выпуска
не нужны, материалы и операции не списываются. Количество выпуска равно количеству
строк ID. Каждый ID уникален; пробелы и специальные символы сохраняются без замены.

Выпущенные товары исключаются из свободного остатка для сборки и повторного выпуска.
Они остаются на складе до продажи по ID или выдачи на замену. Выпуск не изменяет
фактический складской остаток и не увеличивает выполнение производственного плана.
Ревизия проверяет общий физический остаток, включая выпущенные единицы.

Продукты по умолчанию подотчётны. У продаваемого побочного п/ф есть флажок
«Подотчётный»: при включении продажа требует ID каждой единицы. Неподотчётную
продукцию можно продавать анонимно из свободного остатка, а выпущенные единицы — по ID.
Повторный выпуск, повторная продажа ID и превышение свободного остатка запрещены.
Исторические ID сохраняются. Для совместимости старый API производства принимает
ID вместе с производством; интерфейс выпуска использует отдельный `/product-releases`.


Во вкладке «Планирование → Склад» показаны только выпущенные изделия, которые ещё
не проданы и не выданы на замену. Нажмите на строку продукта, чтобы открыть доступные
ID. В «Склад → Продукты» колонка «Выпущенные» показывает это же количество.

В регистрации продажи продукты и продаваемые п/ф показаны в общем списке,
включая позиции с нулевым остатком и без выпущенных ID. У каждой позиции показано
доступное для продажи количество. При отсутствии остатка или ID форма объясняет,
почему продажа пока недоступна. Форма автоматически учитывает подотчётность выбранной позиции:
подотчётная продукция продаётся выбором ID выпущенных изделий (количество
вычисляется автоматически); неподотчётная — вводом количества из свободного
остатка без выбора ID. В списках нет уже проданных
или выданных на замену ID. Позиции и ID загружаются с учётом всех страниц каталога.

Для подотчётных позиций доступность и проверка выбора определяются выпущенными ID,
а не свободным складским остатком. В списке явно показано количество выпущенных
изделий; после выбора — количество доступных ID. Свободный остаток без выпуска
не даёт возможности продать подотчётную продукцию.
